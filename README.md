# LLUCH & YUCH

## Visión general

Este repositorio corresponde a la base documental y técnica para la web de LLUCH & YUCH, una empresa especializada en alisado y pintura, con un enfoque inicial claro en trabajos de preparación, acabado y renovación de interiores.

La web está diseñada para captar clientes con necesidades reales de:

- alisado de paredes
- alisado de techos
- preparación de superficies
- pintura interior
- pintura de viviendas
- pintura de locales
- renovación y acabado de paredes

El proyecto debe crecer de forma controlada y profesional, manteniendo el foco inicial en alisado + pintura, sin limitar la arquitectura a un único servicio.

## Principio de trabajo

El desarrollo posterior debe seguir siempre:

- leer
- entender
- investigar
- planificar
- implementar
- probar
- revisar
- documentar
- cerrar

Nunca improvisar ni codificar sin plan.

## Stack base

El proyecto está pensado sobre:

- Next.js
- React
- TypeScript
- App Router
- SEO integrado desde el inicio
- despliegue profesional
- diseño modular

## Reglas clave

- no se debe añadir dependencia sin justificación documental
- no se debe cambiar la arquitectura sin ADR
- no se debe cerrar una feature sin validación
- no se debe mezclar features distintas en un mismo cambio
- no se debe sobreingenierizar la solución
